# 我的第一个算法项目

这是一个基于 Python 实现的经典算法练习库，主要用于记录和整理学习过程中的算法实现。

## 项目结构
- `dp_tools/`: 动态规划（Dynamic Programming）相关算法实现。
  - `knapsack.py`: 经典的 0/1 背包问题实现。
  - `done.py`: 已完成的其他算法练习。

## 已实现的算法
1. **背包问题 (Knapsack Problem)**:
   - 实现了 0/1 背包问题的最优解寻找。
   - 包含状态转移方程的详细注释。

## 如何运行
确保你已经安装了 Python 3.x，然后在终端运行：
```bash
python dp_tools/knapsack.py
